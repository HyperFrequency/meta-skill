# Markov Regime Detection with hmmlearn

## Overview

A Hidden Markov Model (HMM) assumes observations are generated by an unobserved discrete state
(the "regime") that evolves as a Markov chain. The canonical finance use: fit a 2-3 state
Gaussian HMM on returns and decode each day's most likely regime (e.g. low-vol drift-up "bull",
low-vol drift-down "bear", high-vol "crisis"). States are statistical artifacts, not pre-labeled —
you assign semantic meaning after inspecting per-state means and covariances.

`hmmlearn` is the scikit-learn-style Python HMM library. Two emission models matter here:
`GaussianHMM` (continuous emissions — direct on returns) and `CategoricalHMM` (discrete emissions —
for hand-built signal alphabets).

## When to Use This Skill

Use when:
- Building a regime overlay (e.g. switch a long-only strategy off in detected "crisis" states)
- Estimating regime-conditional return / vol moments for scenario analysis
- Producing a smoothed state probability series `P(state_t | data_{1:T})` for backtesting
- Comparing strategy performance conditional on regime
- Identifying structural breaks in return characteristics

Don't use when:
- You want continuous-state time-varying volatility → use **garch-volatility**
- You need exogenous-variable-driven regime switching → use `statsmodels.tsa.regime_switching.MarkovRegression` / `MarkovAutoregression`
- You want sticky-HDP-HMM / non-parametric state-count selection → use `pyhsmm` or `numpyro`

Related siblings: **garch-volatility** (vol modeling), **statsmodels** (econometric switching models).

## Core Workflow

1. Shape returns to 2D `X` of shape `(n_samples, n_features)` — hmmlearn requires 2D even for univariate.
2. Fit `GaussianHMM(n_components=K, covariance_type=...)` across **10-20 random seeds**; keep the
   converged fit with the highest `score(X)` (EM is init-sensitive — this is the #1 failure mode).
3. Choose `K` by **held-out** `score(X_holdout)`, not in-sample log-likelihood (which always rises with K).
4. `predict(X)` for the Viterbi state sequence; `predict_proba(X)` for smoothed posteriors.
5. **Relabel** states deterministically (e.g. sort by `means_.ravel()`) before any downstream use.

Caution: `predict_proba` returns **smoothed** posteriors that use future data — using them in a
backtest leaks look-ahead. For live regime detection use a filtered/online estimate instead.
