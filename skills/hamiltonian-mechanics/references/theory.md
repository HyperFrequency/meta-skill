# Hamiltonian Mechanics — Analytic Reference

The symbolic machinery you use to reason about a system before integrating it, and the
argument for *why* symplectic integrators conserve energy.

## Hamilton's equations and the Legendre transform

Start from a Lagrangian `L(q, q̇, t)`. Define the conjugate momentum and the Hamiltonian via
the Legendre transform:

```
p_i = ∂L/∂q̇_i          H(q, p, t) = Σ_i p_i q̇_i − L
```

The equations of motion become first-order in phase space `(q, p)`:

```
q̇_i =  ∂H/∂p_i          ṗ_i = −∂H/∂q_i          dH/dt = ∂H/∂t
```

If `H` has no explicit time dependence, `H` (usually the energy) is conserved. Cyclic
coordinates (`∂H/∂q_i = 0`) give conserved conjugate momenta directly.

## Poisson brackets

For observables `f(q, p)` and `g(q, p)`:

```
{f, g} = Σ_i ( ∂f/∂q_i · ∂g/∂p_i − ∂f/∂p_i · ∂g/∂q_i )
```

Key facts:

- Time evolution of any observable: `df/dt = {f, H} + ∂f/∂t`.
- `f` is a **constant of motion** iff `{f, H} = 0` (and no explicit `t`).
- Fundamental brackets: `{q_i, p_j} = δ_ij`, `{q_i, q_j} = {p_i, p_j} = 0`.
- If `{f, H} = 0` and `{g, H} = 0` then `{ {f, g}, H } = 0` (Poisson's theorem): the bracket
  of two invariants is itself an invariant — sometimes a *new* one.

SymPy helper (exact, symbolic):

```python
import sympy as sp

def poisson_bracket(f, g, qs, ps):
    """qs, ps: matching lists of SymPy symbols for coordinates and momenta."""
    return sp.simplify(sum(sp.diff(f, q) * sp.diff(g, p) - sp.diff(f, p) * sp.diff(g, q)
                           for q, p in zip(qs, ps)))

# Example: angular momentum L_z is conserved for a central potential H = (px²+py²)/2 + V(r)
x, y, px, py = sp.symbols('x y px py', real=True)
r  = sp.sqrt(x**2 + y**2)
H  = (px**2 + py**2)/2 + sp.Function('V')(r)
Lz = x*py - y*px
poisson_bracket(Lz, H, [x, y], [px, py])          # → 0
```

## Canonical transformations and generating functions

A change of variables `(q, p) → (Q, P)` is **canonical** if it preserves the fundamental
Poisson brackets (`{Q_i, P_j} = δ_ij`), equivalently if its Jacobian is a symplectic matrix.
Canonical transformations are generated by a function `F`; the four standard types swap which
old/new variables are held independent, e.g.

```
F₁(q, Q):   p = ∂F₁/∂q,   P = −∂F₁/∂Q
F₂(q, P):   p = ∂F₂/∂q,   Q =  ∂F₂/∂P        (identity: F₂ = qP)
```

The goal is to reach coordinates in which `H` is simpler — ideally depending only on the new
momenta, so every new coordinate is cyclic and the motion trivializes. That target is
action-angle variables. The Hamilton–Jacobi equation `H(q, ∂S/∂q) = E` finds the generating
function `S` that achieves it.

## The symplectic 2-form — what integrators preserve

Phase-space flow preserves the 2-form `ω = Σ_i dq_i ∧ dp_i`, hence oriented phase-space area
(Liouville's theorem is the volume corollary). A numerical map `(q,p)_n → (q,p)_{n+1}` is
**symplectic** when its Jacobian `M` satisfies `Mᵀ J M = J` with `J = [[0, I], [−I, 0]]`.
Leapfrog and the Yoshida compositions satisfy this exactly at every step, for any `dt`.

## Why energy stays bounded: backward error analysis

A symplectic integrator's discrete map is the *exact* time-`dt` flow of a nearby **shadow
Hamiltonian**

```
H̃ = H + dt^k · H₁ + dt^{k+1} · H₂ + …          (k = method order)
```

The numerical trajectory therefore lies exactly on level sets of `H̃`, which is conserved.
Since `H̃ = H + O(dt^k)`, the *measured* `H` stays within `O(dt^k)` of its start **for
exponentially long times** — it oscillates but does not drift. A non-symplectic method has no
such conserved shadow, so its energy error accumulates secularly. This, not per-step order, is
why leapfrog beats RK4 over `10^6` steps. (The series for `H̃` is asymptotic, not convergent;
the guarantee holds up to exponentially long times, breaking down near strong resonances.)

## Action-angle variables

For an integrable system with `n` degrees of freedom, motion lives on `n`-tori. The **actions**

```
J_i = (1/2π) ∮_{C_i} p · dq
```

(one loop `C_i` per independent cycle of the torus) are conserved, and the conjugate
**angles** `θ_i` advance linearly: `θ_i(t) = θ_i(0) + ω_i t`, with frequencies
`ω_i = ∂H/∂J_i`. In these coordinates `H = H(J)` alone. Actions are **adiabatic invariants**:
they stay nearly constant when a parameter is varied slowly compared with the orbital period
(the adiabatic theorem). The 1-DOF numerical action integral is in
[diagnostics.md](diagnostics.md).

## KAM theory and the route to chaos

**KAM theorem** (Kolmogorov–Arnold–Moser): under a small perturbation `H = H₀(J) + εH₁(J, θ)`
of an integrable system, most invariant tori survive — specifically those with
"sufficiently irrational" (Diophantine) frequency ratios, slightly deformed. Tori with
frequencies near low-order rational ratios (resonances) are destroyed first, opening chaotic
layers. As `ε` grows, more tori dissolve until the last KAM torus breaks and global chaos
sets in. This is exactly what a sequence of Poincaré sections at increasing energy visualizes
(see [diagnostics.md](diagnostics.md)).

**Chirikov resonance-overlap criterion**: estimate the half-widths (in action) of neighbouring
resonances; when they overlap,

```
K ≡ (Δ_1 + Δ_2) / δ  ≳ 1        (δ = separation between resonances)
```

the tori between them are destroyed and large-scale chaotic transport begins. It is a
heuristic, but a reliable order-of-magnitude predictor of the onset of global chaos.
