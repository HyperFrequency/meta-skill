# Creative Thinking for Research

Eight empirically grounded frameworks from cognitive science, applied to computer science and AI research. Unlike ad-hoc brainstorming, each framework is backed by decades of creativity research — from Koestler's bisociation to Kauffman's adjacent possible. They target distinct cognitive operations: combining, reformulating, analogizing, constraining, inverting, abstracting, exploring boundaries, and holding contradictions.

This file is a router. The full method for each framework — workflows, examples, self-checks — lives in `references/frameworks.md`. Session protocol, block diagnosis, and agent-facilitation guidance live in `references/protocol-and-blocks.md`.

## When to Use This Skill

- Generating genuinely novel ideas, not incremental extensions of prior work
- Feeling trapped in a local optimum of thinking within a single subfield
- Wanting to systematically apply creativity heuristics rather than waiting for inspiration
- Preparing for a research retreat or PhD-level ideation session
- Bridging between fields and seeking structural (not superficial) connections

**Do NOT use this skill when**:
- You need structured project-level brainstorming workflows (use `brainstorming-research-ideas`)
- You have a well-defined problem and need execution help (use domain-specific skills)
- You need a literature survey (use `scientific-skills:literature-review`)

**Relationship to the brainstorm skill**: The brainstorm skill provides operational workflows (diverge → converge → refine) and practical filters. This skill provides the deeper cognitive engines that power creative leaps. Use them together: creative-thinking to generate raw insight, brainstorm to structure and evaluate it.

## The Eight Frameworks

Pick by the cognitive operation you need. Full detail (workflows, examples, self-checks) for each is in `references/frameworks.md`.

| # | Framework | Core operation | Reach for it when |
|---|-----------|----------------|-------------------|
| F1 | **Combinatorial Creativity (Bisociation)** — Koestler | Combine two unrelated frames via a cross-product matrix | All ideas come from one subfield; you want cross-domain combinations |
| F2 | **Problem Reformulation (Representational Change)** — Gestalt / Kaplan & Simon | Re-represent the problem (objective, formalism, granularity, agent, timescale, direction) | You are fixated on one framing of the problem |
| F3 | **Analogical Reasoning (Structure-Mapping)** — Gentner / Dunbar | Map deep causal/relational structure from a distant domain | You need a generative leap; surface analogies aren't enough |
| F4 | **Constraint Manipulation** — Boden | Classify constraints hard/soft/hidden, then relax/tighten/replace | Every idea is "+2% on benchmark X"; you need to change the rules |
| F5 | **Negation and Inversion** — De Bono / TRIZ | Negate a "everyone knows" assumption and build what emerges | You are self-censoring weird ideas before exploring them |
| F6 | **Abstraction & Generalization Laddering** — Polya | Move a result up (generalize) and down (specialize) | You have results with no explanation, or theory with no grounding |
| F7 | **The Adjacent Possible** — Kauffman / Johnson | Map recent enablers and what they newly permit | Analysis paralysis; you need what is feasible right now |
| F8 | **Janusian / Dialectical Thinking** — Rothenberg | Hold two opposites and synthesize a transcending frame | You are stuck choosing between two approaches (false dichotomy) |

## How to Run a Session

1. **Diagnose the block** — match the symptom to a framework using the block table in `references/protocol-and-blocks.md`.
2. **Select 2-3 frameworks** and apply them with the researcher supplying domain content; push for *structural* depth, not surface metaphor.
3. **For a deep session**, run the four-phase protocol (map → disrupt → deepen → evaluate) in `references/protocol-and-blocks.md`.
4. **Evaluate** survivors with the two-sentence test, then hand off to the brainstorm skill for diverge → converge → refine.

**Key principles**: generative mode first, evaluative mode second; distant analogies are more valuable but need more validation; the agent provides cognitive scaffolding, the researcher provides domain knowledge; sit with contradictions rather than resolving them quickly.
